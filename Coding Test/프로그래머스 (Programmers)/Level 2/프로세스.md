```python
from collections import deque
def solution(priorities, location):
    queue = deque()
    order = 0

    for i, pri in enumerate(priorities):
        queue.append((i, pri))

    while queue:
        i, pri = queue.popleft()
        if any(pri < q[1] for q in queue):
            queue.append((i, pri))
        else:
            order +=1
            if location == i:
                return order
```
> **배운점 & 느낀점**
	- enumerate는 index와 value를 동시에 저장할 수 있다.  → index를 기억해야되는 경우에 사용하자
	- any는 list, tuple, set 같은 자료형에서 값을 빼와서 비교할 때 하나라도 True 전부 False면 False를 반환하는 함수이다.
