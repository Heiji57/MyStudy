```python
def solve():
    N = int(input())

    arr = []
    for _ in range(N):
        s, i = input().split()
        arr.append([s, int(i)])

    arr.sort(key=lambda x: x[1])

    for i in range(N):
        print(arr[i][0], end=" ")

if __name__ == '__main__':
    solve()
```
> **배운점 & 느낀점**
	하나의 list 안에는 다른 타입들을 받을 수 있다.
