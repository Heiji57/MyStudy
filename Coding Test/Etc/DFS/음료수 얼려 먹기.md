```python
def solve():
    N, M = map(int, input().split())

    graph = [list(map(int, input())) for _ in range(N)]

    result = 0
    for i in range(N):
        for j in range(M):
            if ice_dfs(i, j, graph):
                result += 1

    return result

def ice_dfs(x, y, graph):
    if x<0 or x >= len(graph) or y<0 or y >= len(graph[0]):
        return False

    if graph [x][y] == 0:
        graph[x][y] = 1
        ice_dfs(x-1, y, graph)
        ice_dfs(x+1, y, graph)
        ice_dfs(x, y-1, graph)
        ice_dfs(x, y+1, graph)
        return True

    return False

if __name__ == '__main__':
    print(solve())
```
> **배운점 & 느낀점**
	- input 값에는 띄어쓰기 없이 들어오는 경우 split을 사용하면 안된다.
	- 함수인 경우에는 언제나 return을 하자.
	- 값이 넘어가지 않도록 하자.
