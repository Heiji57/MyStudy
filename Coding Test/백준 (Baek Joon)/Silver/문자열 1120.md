```python
def diff_length(a, b):
    min_diff = 50
    for i in range(len(b) - len(a) + 1):
        diff = 0
        for j in range(len(a)):
            if a[j] != b[i + j]:
                diff += 1

        if diff < min_diff:
            min_diff = diff

    return min_diff


if __name__ == '__main__':
    a, b = input().split()
    print(diff_length(a, b))
```
> > **배운점 & 느낀점**
> 문자열 자를 때 `a[:c], a[-c:]` 이런식으로 할 수 있다는 걸 알음.
